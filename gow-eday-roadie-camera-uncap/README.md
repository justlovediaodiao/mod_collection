# Gears of War: E-Day Roadie Camera Uncap

Removes the horizontal camera speed limit while  Roadie Run. Controller camera movement keeps its normal response instead of slowing down at the start of a sprint and then suddenly speeding back up.

## Installation

1. Install mod_loader.
2. Create a `mods` directory next to the game executable if it does not already exist.
3. Copy `roadie_camera_uncap.dll` into the `mods` directory.
4. Start the game with Easy Anti-Cheat (EAC) bypassed.
