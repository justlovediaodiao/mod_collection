# Mod Collection

A collection of game mods maintained in a single repository.

| Project | Game | Description |
|---|---|---|
| [`borderlands4_dynamic_fps`](borderlands4_dynamic_fps/) | Borderlands 4 | Switch FPS based on NVIDIA frame generation activity. |
| [`mhwilds_mod_pack`](mhwilds_mod_pack/) | Monster Hunter Wilds | Some lua script mdod based on reframework |
| [`pragmata_dynamic_fps`](pragmata_dynamic_fps/) | PRAGMATA | Switch FPS in menus and during gameplay. |

See each project directory for requirements, installation, configuration, and
build instructions.
